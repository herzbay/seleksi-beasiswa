## 📌 Overview

The **Scholarship Selection Prediction Website** is a web-based project developed to support university scholarship selection through machine learning.

The system applies the **CatBoost Classifier** algorithm to classify scholarship applicants based on criteria such as Grade Point Average (GPA), household income, number of dependents, and other relevant factors.

Built with **HTML, CSS, JavaScript, and Bootstrap**, this project demonstrates the application of machine learning to a scholarship selection scenario.

The project was showcased at **TechnoFest**, a technology exhibition.

> ⚠️ This project serves as a decision-support prototype. Predictions should not replace the university's official scholarship selection process.

## ✨ Features

- 🎓 **Scholarship Prediction** — Classifies applicants using the CatBoost Classifier.
- 📝 **Applicant Criteria** — Uses relevant applicant information as model inputs.
- 🖥️ **Web Interface** — Provides a browser-based interface for interacting with the system.
- 📱 **Responsive Design** — Uses Bootstrap for a responsive user interface.
- 🤖 **Machine Learning** — Demonstrates a classification use case in education.

## 🧠 How It Works

1. 📝 Applicant information is entered through the website.
2. ⚙️ Input data is processed according to the model's requirements.
3. 🤖 The CatBoost Classifier generates a classification prediction.
4. 📊 The prediction result is presented through the website interface.

*The workflow depends on the model and website integration implemented in the project.*
